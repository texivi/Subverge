# Roadmap

## Subverge 0.9.6

- [x] Emacs keys at the prompt, in the pager and in [scrawl](scrawl.md), with `bind`, `unbind`, `bindings` and `describe-key` ([keys](keys.md))
- [x] M-x and the C-h help keys
- [x] [Windows](tabs.md): up to four tabs on the screen at once, opened with Super-Enter or C-x 3 and C-x 2
- [x] [phi](phi.md), a tree of sets for named values, and `dired`
- [x] [Sound](sound.md): a Sound Blaster 16 driver, a synthesizer and six songs that play in the background
- [x] `golden`, and screenshots in the `gallery`

## Subverge 0.9.5

- [x] [Pictures](pictures.md): `bitmap` and the `bmp-` words, `picture` and `pictures`, a JPEG decoder in the kernel
- [x] `gallery`, which shows the built-in pictures, and `credits`
- [x] Graphics mode in 24-bit colour
- [x] The kernel loads past 576 KiB from an installed disk

## Subverge 0.9.4

- [x] The help pages inside the system, read with `docs` and `doc`
- [x] A PS/2 mouse on the text screen, with `mouse` and `mouse?`
- [x] Words for the infinity pages: `pair`, `unpair`, `fusc`, `rational`, `hotel`, `rationals`, `collatz`, `thue`, `prime?` and `ulam`

## Subverge 0.9.3

- [x] `text` draws in [graphics mode](screen.md)
- [x] `window` draws a titled window frame

## Subverge 0.9.2

- [x] `beep`, for the PC speaker
- [x] [Graphics mode](screen.md) with `gfx`, `gfx-off`, `dot`, `box` and `window`

## Subverge 0.9.1

- [x] The `haelide` theme
- [x] [Logos](logos.md) for `sys`, with `logo`, `logos` and `logo@`
- [x] `type` and `fail`

## Subverge 0.9.0

- [x] [Themes](themes.md): `dusk`, `raw`, `paper`, `amber` and `phosphor`, remembered on installed disks
- [x] `rgb` for changing single colours
- [x] Bright background colours
- [x] `redo`
- [x] Tab completion at the [prompt](prompt.md)
- [x] `apropos`
- [x] Text words: `lower`, `trim`, `starts?`, `ends?`, `replace`, `join`
- [x] List words: `reverse`, `sort`, `sum`, `fold`, `index`
- [x] `sqrt` and `gcd`, for bignums too
- [x] `pick`, `tuck` and `2dup`
- [x] `cal`, `month` and `date`
- [x] `tiles`
- [x] Go to line and duplicate line in [scrawl](scrawl.md)

## Subverge 0.8.0

- [x] [Bignums](bignums.md) up to 2^65536
- [x] Compiled code switches to bignums on overflow
- [x] Bignums in comparisons, conditions, `str`, `>num`, `min`, `max` and saved worlds
- [x] `0b` binary literals
- [x] More [learn](learn.md) lessons
