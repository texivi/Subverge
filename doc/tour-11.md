# Part 11: Programs

The programs that come with Subverge are omega, and each one is a word in root. Press Ctrl-M for the menu of programs.

Games: [snake](>snake), [tiles](>tiles), [pong](>pong), [life](>life)

Animations: [rain](>rain), [stars](>stars), [bounce](>bounce), [sorting](>sorting), [mandel](>mandel)

Tools: [calc](>calc), [clock](>clock), [stopwatch](>stopwatch), [todo](>todo), [convert](>convert)

Open a program to see how it works:

    'snake open

Leave the editor with C-x C-c.

A program is a word that can read keys with `key` and draw with `put` and `text`. [Games](games) shows the shape they share, and [apps](apps) explains how to add a program to the menu.

The [demo index](demo-index) lists every program.
